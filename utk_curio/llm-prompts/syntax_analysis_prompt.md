You will receive a description of a dataflow. Your work is to select keywords of the dataflow that denote the keyword types in the configuration below.

A keyword is a single or set of words.

After selecting the keywords output them in the following JSON format:

{
    "keyword1": "keyword1_type"
    "keyword2": "keyword2_type"
    ...
}

The same keyword cannot receive more than one type.

**ONLY OUTPUT THE SPECIFIED JSON NOTHING ELSE. CLASSIFY ONLY THE MOST MEANINGFULL WORDS FOR THE TASK OF THE DATAFLOW DESCRIPTION. DO NOT CLASSIFY MORE THAN 15 words**
