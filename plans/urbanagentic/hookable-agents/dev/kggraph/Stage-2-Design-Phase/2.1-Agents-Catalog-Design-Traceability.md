## Design Rationale and State Model

Memo `12` supersedes the former account-wide installation lifecycle. The authoritative decomposition is:

```text
immutable definition -> explicit private account import -> optional explicit user Publish
          \-> visible built-in/global definition
                         -> explicit project-template Install -> private attached instance
                                                           -> private execution
```

Import, Install, Attach, and Publish are separate explicit commands (there is no agent Share command; agents reuse Curio's existing flow-sharing — D-0 = B). Only owned validated `AccountImportedAgent` definitions are user-publishable. `ProjectAgentTemplate` owns one project's palette/defaults. `AttachedAgentInstance` is private and uses `attachmentId` plus concurrency `revision`, with no SemVer/release/publication/share identity; exact reproducibility pins live on executions.

Mutable settings and prompt governance are decomposed similarly. Deployment/account policy, project-template profiles, instance downward-only overrides, and reservations resolve into an execution snapshot. Prompt Edit/Quality/Compliance Audit/Release belongs only to owned definitions created through explicit account Import; built-in/global definitions, templates, and instances may inspect authorized evidence read-only and cannot edit/Release/Publish. All lifecycle/settings/prompt/history/provider/tool/private-ID data is excluded from the shared result.

## Risks and Dependencies

| ID | Risk | Mitigation |
| --- | --- | --- |
| RISK-ARCH-001 | LangChain/provider details leak into UI/domain. | Enforce runtime/provider ports and import-boundary tests. |
| RISK-STATE-001 | Catalog, palette, attachments, and stream status diverge. | Server authority, normalized caches, revisions, ordered event cursors, idempotency. |
| RISK-SEC-001 | Imported agents or model output invoke unsafe tools. | Declarative manifests, allowlisted tools, authorization, schemas, sandbox, review gates. |
| RISK-SEC-002 | Credentials or sensitive context leak into logs/client/transcript. | Server-side secret references and redaction tests. |
