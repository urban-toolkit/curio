The counter therefore moves into the spec and is bumped at that chokepoint, so every writer inherits it without knowing. The check is deliberately NOT optimistic concurrency: refusing on a stale basis alone would reject ordinary saves, because the canvas learns about an apply through a live event without reloading and a dataset install does not touch the graph at all. A refusal is a 409 naming how many nodes would be lost and telling the user to reload, with their work kept.
