## fine-grained-agent-catalog-right-panel-v1.png

This screen explores the refined direction:

- the **right panel** is an Agent Catalog, consistent with Curio's Data and Node Catalog pattern
- the catalog lists **general reusable agents**, not problem-specific dataflows
- the canvas shows an **example composition** made from those reusable agents
- problem-specific workflows such as climate resilience or mobility analysis are treated as compositions, not catalog units

Key visible agent units:

- Find Datasets Agent
- Preview Dataset Agent
- Load Data Agent
- Clean Data Agent
- Compute Indicator Agent
- Generate Map Agent
- Evaluate Workflow Agent
- Explain Results Agent
