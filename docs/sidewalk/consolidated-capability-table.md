# Consolidated Autark–Grammar–Curio capability table

Source: user-supplied `Autark_Grammar_Curio_Gap_Analysis.xlsm`, **Sheet2**, cells **A1:D37**, extracted October 19, 2026. All 36 populated requirement rows and the four columns below are preserved verbatim. No macros were executed; the workbook is not distributed with this PR.

- **What already exists** identifies capabilities in Map, Plot, Compute, DB, Grammar, or Curio.
- **Remaining work** identifies the responsible component or repository.
- **Sidewalk priority** distinguishes prerequisites, verification needs, optional improvements, and broader audit work.
- **Required** identifies a dependency of the intended behavior. It does not mean the dependency is satisfied or must be implemented in this PR.

Rows carrying C001–C073 refer to the [October 9 historical audit](autark-grammar-curio-audit.md), with its examined versions and limits. “Newer finding” rows incorporate the [October 19 selection investigation](map-selection-investigation.md). Their confirmed event-information loss is distinct from unverified version compatibility or browser concerns. This is a backlog and dependency table, not a statement that every row is delivered or needed in Phase 2.

Current upstream emits the resulting selection set without the individual clicked feature. Different hits, repeated hits, and misses can produce identical payloads; an editor cannot recover the hit reliably by guessing. The separate saved-grammar discrepancy remains unverified; see the [implementation manifest](../../packages/curio.sidewalk-stewards@1/IMPLEMENTATION.md).
