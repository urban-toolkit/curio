## Examples

Each example below has a JSON dataflow you can import into Curio plus a step-by-step markdown walkthrough.

The same examples are also seeded into the public deployments at [**flow.urbantk.org**](https://flow.urbantk.org) (stable) and [**dev.urbantk.org**](https://dev.urbantk.org) (latest `main`). Sign in to fork them into your own projects, or open them as a guest, who can change and run them but not save them.

More on the examples in the [Curio guide](https://curio.urbantk.org).

Icons indicate the complexity level of each example: 🟢 Beginner, 🟡 Intermediate, 🔴 Advanced.
